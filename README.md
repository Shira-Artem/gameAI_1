## Постановка задачи
Реализовать поведение NPC-стражника, патрулирующего набор waypoints в 2D-проекте на Python/pygame. Стражник должен:
- [ ] Идти от waypoint к waypoint в режиме патруля.
- [ ] При обнаружении игрока (raycast в FOV без препятствий) переходить в режим тревоги (Alert).
- [ ] После 1 секунды в Alert при сохранении видимости — начать преследование (Chase).
- [ ] При попадании игрока в зону атаки (1.5 м) — атаковать.
- [ ] При потере цели на N секунд — переходить в Search и обходить «последнюю известную позицию».
- [ ] Если в Search не нашёл цель за 10 секунд — возвращаться к патрулю.

## Сцена pygame

В `main.py` рисуются игрок, стражник, четыре точки патруля, поле зрения,
радиус слуха и последняя известная позиция игрока при поиске.
